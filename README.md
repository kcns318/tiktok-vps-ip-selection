## 为什么 TikTok 对 IP 这么挑：三类 IP 的风控待遇差在哪

TikTok 的风控对 IP 属性极其敏感。同样一条视频、同样的发布节奏，挂在机房 IP 上和挂在居民宽带上，冷启动的流量曲线能差出一个数量级。

按风控评分从差到好，市面上的 IP 大致分三层。

**第一层：机房 IP / 数据中心 IP。** WHOIS 一查就是 hosting 段，ASN 挂在云厂商或 IDC 名下。这类 IP 在平台眼里等于自带「批量注册」标签，常见后果是新号注册即触发人机验证、视频发出去冷启动流量接近 0、直播间被限制观看人数，严重的直接封号。很多人以为自己内容不行，其实是机器从第一天就被判了死刑。

**第二层：原生 IP。** IP 的归属国和广播方是该国本地 ISP，平台查出来是「本地 IP」，不再是明显的数据中心段。原生 IP 比机房段好一个档次，但原生不等于住宅——不少原生 IP 依然挂在商业或机房 ASN 下，做视频发布够用，做直播和长期养号还是有风险。

**第三层：原生家宽 IP / 双 ISP 家宽 IP。** 模拟真实居民宽带环境，IP 归属地显示为住宅宽带，风控评分天然更低。双 ISP 指的是这条 IP 同时具备两个上游运营商的属性，兼顾住宅身份和商业线路质量，在矩阵号和直播场景里稳定性最好。

自己验也不难：把拿到的 IP 丢进 scamalytics 看欺诈评分，再去 ipinfo 一类工具看 ASN 和组织名——组织名写的是 Cloudflare、DigitalOcean、某 IDC，那就是机房段；写的是 Comcast、Verizon、AT&T 这类运营商，才是住宅属性。

## 光有 IP 不够：线路和流量决定了你能不能直播

IP 决定账号能不能活，线路决定你能不能播。

国内到海外机房的走法，电信、联通、移动三家的路由经常完全不是一回事。有的机房对联通直连、对电信绕半个地球，延迟翻倍，直播推流就开始卡顿、掉帧、掉线。判断标准很简单：**能不能三网直连**。能直连就不要加中转，中转机本身就是一笔额外月费和一层额外故障点。
